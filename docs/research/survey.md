# Short survey (2 minutes, WhatsApp or form, any language)

Send after the interviews, to a wider group, to put numbers on what we heard. Anonymous. No names, no phone numbers stored with answers. State at the top: "This is a survey about period pain and apps. Answers are anonymous. You can stop any time."

1. Age group: 18-24 / 25-34 / 35-44 / 45+ / prefer not to say
2. Where do you live: village / small town / city
3. In the last 3 months, did period pain stop you from something (school, work, going out)? Never / once / 2-3 times / most periods
4. How do you track your period? Don't / memory / calendar / an app (which?)
5. If you stopped using an app, why? (pick any) Paywall / privacy worry / dates were wrong / embarrassing notifications / not in my language / forgot / other
6. Which would help you most? (pick one) Knowing when pain is coming / what to do about pain / a doctor I can trust / knowing if my period is normal / nothing
7. Where would you rather use it? WhatsApp / app / both / neither
8. Would you be okay with a coded reminder like "your personal weather forecast" instead of the word period? Yes / No / Not sure
9. Do others see your phone? Never / sometimes / often
10. One line: what do period apps get wrong?

**Reading the results:** report counts, not percentages, under 50 answers. Compare Q3 with Q6 and Q9. Q8 and Q9 decide whether DISCREET mode should be the default.
